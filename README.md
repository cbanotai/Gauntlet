# Running a gauntlet of mammals

Data and R code supporting:

Banotai CM, Farren C, Walker WL, Barber BA, Spencer CR,
Stokes MK, and Koprowski JL.

## Study
This repository contains data and code used to evaluate rodent seed and
seedling damage, marula seedling occurrence, and antelope site use in
Olifants West Nature Reserve, South Africa.

## Repository structure
- `data/raw/` – source data released with the study
- `data/processed/` – analysis-ready datasets
- `data/metadata/` – metadata and supporting documentation
- `scripts/` – R analysis scripts
- `outputs/tables/` – derived analytical tables
- `outputs/figures/` – manuscript figures

## Reproducing the analysis
Run scripts in numerical order.

## Camera-trap analysis
Independent events were defined using a 15-min same-species,
same-site rule. Camera effort was reconstructed from service records,
and weekly detections were standardized to 28 camera-days.

## Sensitive spatial data
Exact camera-site coordinates are withheld because the sites occur
within a privately managed wildlife reserve. Site identifiers and
derived spatial covariates are provided instead.

## Software
Analyses were conducted in R. Package and version information is
provided in `docs/sessionInfo.txt`.
